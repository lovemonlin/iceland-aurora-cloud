冰島旅行資料庫 Chrome 插件｜隱私權政策

最後更新：2026 年 8 月 24 日

插件用途

本插件在使用者瀏覽 Google Maps、選取冰島地點並主動點擊插件按鈕時，辨識目前選取的地點並顯示冰島旅行景點摘要。

處理的資料

插件只在使用者主動點擊時，暫時讀取目前 Google Maps 分頁的網址、可見景點名稱、副標題，以及網址中可取得的地圖座標。這些資料只在使用者裝置上即時處理，用於比對景點資料卡。

資料儲存、傳送與分享

  • 不儲存、建立或同步使用者的瀏覽紀錄。
  • 不將目前 Google Maps 的網址、頁面文字或座標傳送給開發者。
  • 不蒐集姓名、Google 帳號、電子郵件、Cookie、表單內容或精確裝置位置。
  • 不使用廣告、分析追蹤或個人化行銷，也不出售使用者資料。

插件會透過 HTTPS 從 lovemonlin.github.io 下載公開的景點 JSON、公告與景點圖片。一般網路連線可能依 GitHub Pages 的政策向其提供 IP 位址等標準連線資訊；本插件不在請求中加入帳號、廣告識別碼或瀏覽內容。

外部連結

使用者可自行點擊 LINE、Facebook、YouTube 或未來的 Android App 連結。開啟後的網站依各自的隱私權政策運作，本插件不會代替使用者自動傳送資料。

權限用途

  • activeTab：使用者點擊插件後，暫時存取目前分頁。
  • scripting：執行插件內建程式，讀取目前可見的 Google Maps 景點資訊。
  • lovemonlin.github.io：取得公開景點資料、公告與圖片。

政策遵循與聯絡方式

本插件對資料的使用遵循 Chrome Web Store User Data Policy，包括 Limited Use 要求。若有隱私相關問題，請聯絡 hojenjen2018@gmail.com。

Iceland Travel Database Chrome Extension — Privacy Policy

Last updated: August 24, 2026

Purpose

When a user selects an Iceland location in Google Maps and actively clicks the extension button, the extension identifies the selected place and displays a concise Iceland travel card.

Data processed

Only after the user clicks the extension, it temporarily reads the active Google Maps tab URL, visible place name, subtitle, and map coordinates available in the URL. This information is processed locally on the user's device solely to match the selected place with a travel card.

Storage, transmission, and sharing

  • The extension does not store, create, or synchronize browsing history.
  • It does not send the active Google Maps URL, page text, or coordinates to the developer.
  • It does not collect names, Google Accounts, email addresses, cookies, form data, or precise device location.
  • It uses no advertising, analytics tracking, or personalized marketing, and it does not sell user data.

The extension downloads public place JSON, announcements, and place images from lovemonlin.github.io over HTTPS. Standard network requests may provide connection information such as an IP address to GitHub Pages under its own policies. The extension adds no account identifier, advertising identifier, or browsing content to these requests.

External links

Users may choose to open LINE, Facebook, YouTube, or a future Android App link. Those websites operate under their own privacy policies. The extension does not automatically send data to them.

Permission use

  • activeTab: temporarily accesses the active tab after the user clicks the extension.
  • scripting: runs bundled extension code to read visible Google Maps place information.
  • lovemonlin.github.io: retrieves public place data, announcements, and images.

Compliance and contact

The extension's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Privacy questions may be sent to hojenjen2018@gmail.com.
